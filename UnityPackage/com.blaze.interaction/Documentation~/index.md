# Blaze Interaction SDK 1.1.0

1. 在 Project Settings > Blaze Interaction 配置至少一个有效 Surface。
2. GameObject > Blaze Interaction > Create Runtime。
3. 导入 Basic Interaction Sample。
4. Play Mode 首次选择 Radar 或 CameraVision。

公共入口是 `InteractionManager.Instance`。`PixelPosition` 为中心点，`Fp` 为 Radar 实际扫描点或 Camera 21 个骨骼点。

完整安装、API、图文界面和扩展文档位于项目仓库：

https://github.com/blaze-tc/BlazeInteraction
