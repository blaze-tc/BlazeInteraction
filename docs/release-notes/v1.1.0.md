# Blaze Interaction SDK 1.1.0

这是 Radar + CameraVision 统一平台的首个完整演示发布。Unity 可直接下载并通过 **Add package from tarball...** 导入 `com.blaze.interaction-1.1.0.tgz`。

## 新增

- CameraVision 多手检测；每只手输出中心点和 21 个骨骼点。
- Camera 原始画面 + 骨骼/四角标定叠加，以及最终 Unity 点位预览。
- 摄像头、分辨率、帧率下拉选择；检测/跟踪阈值、EMA、X/Y 翻转和 Unity Surface 分辨率换算。
- 首次 Radar/CameraVision 模式选择、自动记忆、控制台返回切换和每项目独立配置。
- 通用 `InteractionPoint.Fp`：Radar 实际扫描点或 Camera 骨骼点。
- Basic Interaction 的短生命周期 `Fp` 粒子和手骨骼演示。

## Radar 与稳定性修复

- 保留 F10/F20、Simulation/Replay、过滤、标定、融合、跟踪和交互行为。
- 修复控制台导航初始化、Bridge 握手后发布竞争和 Camera native crop 错误边界。
- 高频点云/预览采用有界快照、自绘和调度合并，降低滚动、拖框、resize 和高点数场景的卡顿/崩溃风险。

## 安装

下载本 Release 的 `com.blaze.interaction-1.1.0.tgz`，在 Unity Package Manager 选择 **Add package from tarball...**。支持 Unity 2021.3+、Windows x64；Bridge 为 self-contained，无需另装 .NET Runtime。

详细步骤见仓库 [INSTALL.md](https://github.com/blaze-tc/BlazeInteraction/blob/v1.1.0/INSTALL.md)，功能和开发文档见 [docs/README.md](https://github.com/blaze-tc/BlazeInteraction/blob/v1.1.0/docs/README.md)。
