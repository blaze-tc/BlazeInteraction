# Blaze Interaction SDK 1.1.1

这是 v1.1.0 的 CameraVision 显示修复版本，保持 Interaction IPC 1、Unity `InteractionManager` / `InteractionPoint` API 以及 Radar 行为不变。

## 修复

- 修复 CameraVision 使用降采样诊断预览时，标定四角仍按摄像机实际分辨率直接绘制，导致右侧和底部控制点越出画面的问题。
- 修复同一降采样场景下手部骨骼、轮廓和 tracking point 与摄像机画面错位的问题。
- “重置为完整画面”现在会将四个控制点正确显示在摄像机预览边界内。
- 标定点拖拽、实际摄像机坐标存储、透视换算和发送到 Unity 的输出坐标保持原有语义。

## 安装

下载本 Release 的 `com.blaze.interaction-1.1.1.tgz`，在 Unity Package Manager 中选择 **Add package from tarball...**。

也可以固定 Git 标签安装：

```text
https://github.com/blaze-tc/BlazeInteraction.git?path=/UnityPackage/com.blaze.interaction#v1.1.1
```

支持 Unity 2021.3+、Windows x64。Bridge 为 self-contained 发布，不要求目标电脑单独安装 .NET Runtime。
